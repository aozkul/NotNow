# NOT NOW GitHub Pages

Hedef: https://aozkul.github.io/NotNow/

Bu klasörün **içindeki dosyaları** aozkul/NotNow repository'sinin köküne yükle. Settings → Pages → Deploy from a branch → main → /(root) → Save.

- `index.html`: Türkçe ana sayfa; `index-en.html` ve `index-de.html`: diğer diller.
- `support.html`, `privacy.html`: Türkçe destek ve gizlilik.
- `support-en.html`, `privacy-en.html`: İngilizce.
- `support-de.html`, `privacy-de.html`: Almanca.
- `style.css`: yerel stiller; bağımlılık veya derleme yok.
- `.nojekyll`: statik yayın dosyası.

Destek e-postası: ali.ozkul@icloud.com.

Yayından önce: gerçek yayıncı/şirket adını ve faaliyetin için gereken yasal iletişim/Impressum bilgilerini ekle. Bu bilgiler paylaşılmadığı için uydurulmadı. Sayfalardaki veri davranışı mevcut uygulamaya göre yazıldı; e-posta saklama uygulamanı da doğrula. App Store gönderiminden önce bağlantıları oturum açmadan test et.

Buraya Xcode kodunu, satın alma testlerini veya kullanıcı yedeklerini yüklemek gerekmiyor. Üst klasördeki App Store rehberi ve review-only görseller web sitesinin parçası değildir.
